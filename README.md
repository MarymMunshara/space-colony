# 🚀 Space Colony

A futuristic and interactive **Space Colony** web project built using **HTML, CSS, and JavaScript**.

## ✨ Features

* 🌌 Futuristic space-themed UI
* 🚀 Interactive Space Colony interface
* 🏠 Colony management concept
* ⚡ Dynamic JavaScript interactions
* ✅ Form validations
* 📱 Responsive design
* 🎨 Modern futuristic styling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
space-colony/
├── index.html
├── style.css
├── script.js
└── README.md
```


## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or dependencies are required.
